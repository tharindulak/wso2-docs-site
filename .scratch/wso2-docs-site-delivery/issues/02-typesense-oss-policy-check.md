## Question

The Typesense server is GPL-3.0. Run unmodified as a separate service, it is not linked into the site, but `docs-site/README.md` says it must be checked against WSO2's OSS policy before use beyond development. Get that check from the right WSO2 owner (legal or OSS office) for running it in production on the VM. Resolution records the answer, who gave it and any conditions; a refusal reopens the search engine choice on the [WSO2 docs site on Docusaurus](../../wso2-docs-site/map.md) map.
