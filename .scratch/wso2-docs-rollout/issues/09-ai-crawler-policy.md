## Question

Get an owner's decision on whether the docs site's `robots.txt` allows AI crawlers (GPTBot, ClaudeBot, PerplexityBot, Google-Extended and the like), and whether that differs from wso2.com's current policy. The recommendation from [AI-friendly docs scope](07-ai-friendly-docs.md) is to allow them, because the docs are public and meant to be found.

## Checklist (for the human)

- [ ] Find who owns crawler policy for wso2.com (marketing or legal), and note today's `robots.txt` on wso2.com and the current docs sites.
- [ ] Ask them: allow all AI crawlers on the docs site, allow only some, or block?
- [ ] Record the answer, who gave it, and the date in this ticket's resolution.
