# Source of truth for each cross-cutting fact

Parent: [map](../map.md)
Type: grilling
Status: open
Blocked by: 01, 03

## Question

For each cross-cutting fact the hub will state (SLA, regions and data residency, billing and plans, security and compliance, support tiers, status), which single source does the hub treat as authoritative, who owns it, and does the hub restate the fact or link to it? Include the WSO2 Cloud account itself: who confirms its launch date and billing model, and who approves announcing it (see [What "WSO2 Cloud" means to a customer](07-what-wso2-cloud-means.md)).
