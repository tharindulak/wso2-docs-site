## Question

What is the hub's site tree: top-level sections, the cross-cutting topics under each, one page per product (with its "Deployment options" section and links out), and the single "Product names" page? Every node must say whether the hub owns it or links out.

## Answer

Resolved with the user, 2026-10-05. Full tree and template: [Hub site tree](../assets/04-hub-site-tree.md).

- Grouped by reader task: Overview, Get started, Products, Account and administration, Trust and support, Reference.
- "How the products fit together" is a diagram plus one paragraph per relationship; no end-to-end scenarios for now.
- Hub owns Organizations and users and Enterprise login concept pages; products link in. The near-duplicate org/enterprise-login pages in API Platform and Integration Platform join the gap list for product teams.
- Every product page uses one four-section template (what/when, deployment options, links, related products); no feature lists.
- Status and Support are single hub pages with per-product tables linking out.
- API Analytics Platform page states it is powered by Moesif, links moesif.com/docs, and covers Moesif Basic in API Platform.
