# Map: Migrate Identity Platform docs (docs-is) to Docusaurus

Label: wayfinder:map

## Destination

A reviewable pull request on the fork [tharindulak/docs-is](https://github.com/tharindulak/docs-is) that adds a `docusaurus/` tree, generated by our converter, beside the untouched MkDocs `en/` tree. It holds the unified Latest (Asgardeo merged with Identity Server 7.3.0) and every older IS version with source (7.2.0 to 5.9.0) as frozen versioned docs, plus a contributor guide and a CI check. A Wso2-Cloud branch proves it: the docs site reads Identity Platform from the fork as a `docusaurus` source and builds.

- Standing decisions from charting (2026-10-13):
  - Repo shape: content only, in Docusaurus's native layout (`docs/`, `versioned_docs/version-<v>/`, `versioned_sidebars/`, `versions.json`, `static/`) under `docusaurus/` at the repo root. No standalone site config; writers preview through the docs site's local override.
  - `en/` stays until the IS team signs off on [Cutover](../../CONTEXT.md).
  - Until cutover the `docusaurus/` tree is **generated only**: every fix goes into the converter or into the MkDocs source (duplicates are fixed by rewriting wrapper pages so they merge). One command reproduces the tree; hand edits in MDX start after cutover.
  - Includes: MDX partials for Latest (only where more than one page shares them), inlined for frozen older versions.
  - Merged-page quality: commit as generated; the PR may not merge while any shared page renders as two stacked copies (93 at c2176fc: 49 converter-fixable, 44 need source rewrites).
  - Excluded pages (14 failing across 5 IS versions at 13256c36): fix the converter first, the MkDocs source for what's left.
  - The PR ships a contributor guide (allowed MDX components, preview) and a CI check (MDX compile plus the HTML allow-list, extended to MDX's own risks).
- Skills every session should consult: grilling, domain-modeling. Research tickets use research; prototype tickets use prototype; code changes use tdd.
- Outward-facing: push to and open PRs only on the user's fork. Never push to or open PRs on `wso2/docs-is`.
- Security: the HTML allow-list does not run on `docusaurus` sources today; it must before cutover (see [Docusaurus tree format decisions](issues/12-tree-format-decisions.md) and [Authored-MDX contract and CI check for docs-is](issues/08-authored-mdx-contract.md)).
- Security review needed: the converter does not escape a `{` opening `{/*`, which may let MDX expressions through build-time conversion for every product (from [Locking down authored MDX](issues/03-mdx-authoring-risks.md)).
- Flag supply-chain risk in how the fork's CI gets the converter (unpublished package, personal fork, unpinned refs).
- Treat findings as planning input for human review.

## Decisions so far

<!-- one line per closed ticket -->

- [What the docs site's docusaurus source kind needs to carry Identity Platform](issues/01-docusaurus-source-kind.md): versions, redirects-by-lock and labels already work; six bugs (static path, partials as pages, banner flag, exclude URLs) and missing redirect_maps, promotion and HTML allow-list for `docusaurus` sources; ten format choices open.
- [Locking down authored MDX: what a content-repo check must reject](issues/03-mdx-authoring-risks.md): MDX runs JS in the build with Node access; the regex HTML policy misses every MDX vector; an allow-list remark plugin in the converter, shared by check and build, can reject exports, expressions, unlisted imports and components.
- [Why 119 shared Identity pages render as stacked copies](issues/02-why-shared-pages-stack.md): 93 stack today, not 119; any wrapper difference stacks the whole page; 49 clear with converter work (include alignment, per-option API specs), 44 need MkDocs source rewrites, some touching includes shared with frozen versions.
- [Clone the fork and record a conversion baseline](issues/04-clone-and-baseline.md): fork cloned to `git/docs` on branch `docusaurus-migration`, one commit past the pinned SHA; all 9 versions convert (6,513 pages), 14 pages fail with 7 causes, 93 stack in Latest; output is about 4.2 GB because images are copied per version.
- [Docusaurus tree format decisions](issues/12-tree-format-decisions.md): images shared by file path in immutable `assets/` (3.46 to 1.33 GB); lock file owns versions; `_partials/` without front matter; global components; `redirects.json` in the tree; edit links to `en/` until cutover; strict compile; JSON sidebars; relative `.md` links; allow-list plugin in check and build.
- [Includes as MDX partials in Latest](issues/05-includes-as-partials.md): 93% of includes only joined the Asgardeo and IS copies of one page, so the merge inlines them; 48 shared ones become partials named after their include path; `<Applies>` hides blocks a page does not cover; no props needed; partial headings reach the TOC.
- [Converter writes the docusaurus/ tree](issues/09-generate-docusaurus-tree.md): `migrate-docusaurus.mjs` on branch `docs-is-migrate` writes a deterministic 1.1 GB tree (6,568 pages, 40 partials, assets shared by path); committed locally in the fork as `88d0ab970`; not yet built by Docusaurus.

## Out of scope

- Opening a PR on `wso2/docs-is`, or cutover itself (deleting `en/`): needs the IS team's agreement; follows this map.
- Migrating other products' content sources: Identity Platform first; others are a fresh effort.
- Editorial rewrites of the merged pages beyond removing stacked duplicates (290 `<Applies>` blocks, ~600 `<DeploymentValue>` pairs).
- IS versions with no source (5.0.0 to 5.8.0): they stay as Confluence links.
- Retiring is.docs.wso2.com or the Asgardeo docs site.
