## Question

What does each footer column and call-to-action link to? The design has Docs, Platform and More columns (Community Forum, GitHub, Status, Blog, Contact Support), an "Open the Cloud Console" button, a "Start Building" button and legal links (Privacy Policy, Terms of Use, Security). Take targets from the [WSO2 Cloud hub documentation plan](../../wso2-cloud-docs/map.md) decisions (support and status channels, hub sections); drop any link without an owner; product names follow CONTEXT.md.

## Answer

Decided with the user, 2026-10-19 (recommendations accepted):

- Columns follow the hub and CONTEXT.md, not the design's placeholders. **Docs**: Overview, Get started, Account and administration, Trust and support, Reference (hub sections). **Products**: Agent Manager, Identity Platform, API Platform, Integration Platform, API Analytics Platform. **Help**: Status and Support (the hub's single pages with per-product tables).
- Community Forum, GitHub and Blog are dropped for launch: no owner of a docs-wide target ("Edit this page" already links each page to its source).
- "Start Building" goes to the hub's Get started page. "Open the Cloud Console" is held back until the WSO2 Cloud account console address is confirmed and approved; switched on with one change then.
- Legal row: Privacy Policy and Terms of Use point to WSO2's company-wide pages, addresses confirmed by their owner (not guessed); Security points to the hub's Security and compliance page.
